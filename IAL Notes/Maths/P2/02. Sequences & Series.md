# Pure Mathematics 2: Sequences and Series

## 1. Arithmetic Progressions (AP)
An arithmetic progression is a sequence where the difference between consecutive terms is a constant, denoted as the common difference $d$.

### Key Formulas
* $n$-th term ($u_n$):
  $$u_n = a + (n-1)d$$
  Where $a$ is the first term and $d$ is the common difference.
* Sum of the first $n$ terms ($S_n$):
  $$S_n = \frac{n}{2}[2a + (n-1)d]$$
  $$S_n = \frac{n}{2}[a + l]$$
  Where $l$ is the final term ($l = u_n$).

### Derivation of $S_n$
1. Write the sum forward: $S_n = a + (a+d) + (a+2d) + \dots + (l-d) + l$
2. Write the sum backward: $S_n = l + (l-d) + (l-2d) + \dots + (a+d) + a$
3. Add the two equations together: $2S_n = (a+l) + (a+l) + \dots + (a+l)$ (repeated $n$ times)
4. Simplify: $2S_n = n(a+l) \implies S_n = \frac{n}{2}(a+l)$

## 2. Geometric Progressions (GP)
A geometric progression is a sequence where each term after the first is found by multiplying the previous term by a non-zero fixed constant, denoted as the common ratio $r$.

### Key Formulas
* $n$-th term ($u_n$):
  $$u_n = ar^{n-1}$$
* Sum of the first $n$ terms ($S_n$):
  $$S_n = \frac{a(1-r^n)}{1-r} = \frac{a(r^n-1)}{r-1}$$

### Derivation of $S_n$
1. Express the sum: $S_n = a + ar + ar^2 + \dots + ar^{n-1}$
2. Multiply by $r$: $rS_n = ar + ar^2 + ar^3 + \dots + ar^n$
3. Subtract the first equation from the second: $rS_n - S_n = ar^n - a$
4. Factorise: $S_n(r-1) = a(r^n-1) \implies S_n = \frac{a(r^n-1)}{r-1}$

## 3. Convergent Series and Sum to Infinity
A geometric series is convergent if and only if the absolute value of its common ratio is strictly less than 1.
$$|r| < 1 \iff -1 < r < 1$$
If a series converges, as $n \to \infty$, $r^n \to 0$. The sum to infinity ($S_\infty$) is defined as:
$$S_\infty = \frac{a}{1-r}$$

## 4. Sigma Notation
The symbol $\sum$ represents summation.
$$\sum_{r=1}^{n} u_r = u_1 + u_2 + u_3 + \dots + u_n$$
Linear combinations can be separated:
$$\sum (A u_r + B v_r) = A \sum u_r + B \sum v_r$$

## 5. Binomial Expansion
The binomial expansion allows for the expansion of expressions of the form $(a + b)^n$. For Pearson P2, $n$ is restricted to a positive integer.

### Binomial Coefficients
$$\binom{n}{r} = {}^{n}C_r = \frac{n!}{r!(n-r)!}$$
Where $n! = n \times (n-1) \times \dots \times 1$.

### General Formula
$$(a+b)^n = a^n + \binom{n}{1}a^{n-1}b + \binom{n}{2}a^{n-2}b^2 + \dots + \binom{n}{r}a^{n-r}b^r + \dots + b^n$$
If $a = 1$ and $b = x$:
$$(1+x)^n = 1 + nx + \frac{n(n-1)}{2!}x^2 + \frac{n(n-1)(n-2)}{3!}x^3 + \dots$$

### Key Approximation Rules
To find approximations for numbers (e.g., $1.02^5$), substitute an appropriate value of $x$ (e.g., $x=0.02$ into $(1+x)^5$) and evaluate up to the required degree of accuracy. The expansion is valid for all values of $x$ when $n$ is a positive integer.
