# 03 - Trigonometry

## 1. Triangles (Degrees/Radians)
For an arbitrary triangle with sides $a, b, c$ opposite angles $A, B, C$:
* **Sine Rule:** $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$
* **Cosine Rule:** $a^2 = b^2 + c^2 - 2bc \cos A$
* **Area of Triangle:** $\text{Area} = \frac{1}{2}ab \sin C$

> [!WARNING] The Ambiguous Case
> When applying the Sine Rule given an angle, an adjacent side, and an opposite side (SSA configuration), check if two valid triangles exist. $\sin 	heta = \sin(180^\circ - 	heta)$.

## 2. Circular Measure (Radians Only)
$\pi 	\text{ radians} = 180^\circ$. Ensure your calculator is set to the correct mode!
* **Arc Length:** $s = r	\theta$
* **Sector Area:** $A = \frac{1}{2}r^2 \theta$

## 3. Trigonometric Identities
Fundamental identities to use in equations and proofs:
1. $\tan \theta \equiv \frac{\sin \theta}{\cos \theta}$
2. $\sin^2 \theta + \cos^2 \theta \equiv 1$

## 4. Solving Trigonometric Equations
When solving equations across an interval (e.g., $0 \leq 	\theta \leq 360^\circ$):
1. Isolate the trigonometric term (e.g., $\sin x = k$).
2. Compute the principal value: $\theta = \sin^{-1}(k)$.
3. Use a CAST diagram or quadrant graphs to identify secondary values within the interval bounds.
4. Adjust boundary limits if the variable argument inside the trigonometric term is altered (e.g., if finding solutions for $2\theta$, multiply the original range constraints by two).
