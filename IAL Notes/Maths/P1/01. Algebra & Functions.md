# 01 - Algebra & Functions

## 1. Laws of Indices & Surds
For all real values of $a, b$ and rational exponents:
* $a^m \times a^n = a^{m+n}$
* $a^m \div a^n = a^{m-n}$
* $(a^m)^n = a^{mn}$
* $a^{-n} = \frac{1}{a^n}$
* $a^{1/n} = \sqrt[n]{a}$
* $a^{m/n} = (\sqrt[n]{a})^m$

### Surd Manipulations
* $\sqrt{ab} = \sqrt{a}\sqrt{b}$
* $\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$
* Rationalizing denominators: Multiply numerator and denominator by the conjugate pair (e.g., for $\frac{1}{a + \sqrt{b}}$, multiply by $a - \sqrt{b}$).

## 2. Quadratic Equations
A quadratic expression takes the form $ax^2 + bx + c = 0$.

### The Discriminant ($\Delta$)
The nature of the roots is determined by:
$$\Delta = b^2 - 4ac$$
* $\Delta > 0$: Two distinct real roots (intersects x-axis twice).
* $\Delta = 0$: Two equal real roots / one repeated root (tangent to x-axis).
* $\Delta < 0$: No real roots (does not intersect x-axis).

### Completing the Square
Transforming $ax^2 + bx + c$ into the vertex form $a(x + p)^2 + q$:
1. Factor out $a$: $a[x^2 + \frac{b}{a}x] + c$
2. Half the coefficient of $x$: $a[(x + \frac{b}{2a})^2 - (\frac{b}{2a})^2] + c$
3. Expand out outer bracket: $a(x + \frac{b}{2a})^2 - \frac{b^2}{4a} + c$
* **Vertex / Turning Point Coordinate:** $(-\frac{b}{2a}, c - \frac{b^2}{4a})$
* Axis of symmetry is $x = -\frac{b}{2a}$.

## 3. Simultaneous Equations & Inequalities
* **Linear & Non-linear:** Always isolate a linear variable from the simpler equation and substitute it directly into the non-linear equation. Never try elimination when dealing with squares or products.
* **Quadratic Inequalities:** Always find critical values by setting the quadratic to zero. Sketch the curve! 
  * If $ax^2 + bx + c < 0$, choose the region *below* the x-axis (between roots).
  * If $ax^2 + bx + c > 0$, choose the regions *outside* the roots.

## 4. Graph Transformations
Given the base function $y = f(x)$:
* $f(x + a)$: Horizontal translation by vector $\begin{pmatrix} -a \ 0 \end{pmatrix}$
* $f(x) + a$: Vertical translation by vector $\begin{pmatrix} 0 \ a \end{pmatrix}$
* $f(ax)$: Horizontal stretch, scale factor $\frac{1}{a}$
* $a f(x)$: Vertical stretch, scale factor $a$
